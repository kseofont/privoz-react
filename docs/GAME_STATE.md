# 1. Цель проекта

"Привоз" - многопользовательская настольная игра на React + PeerJS.

Главная текущая задача разработки:

1. Не переписывать рабочий прототип с нуля.
2. Сохранить существующий игровой flow.
3. Постепенно вынести игровые правила из React-компонентов и legacy `logic.js`.
4. Сделать HOST единственным авторитетным источником `gameState`.
5. После стабилизации архитектуры реализовать полноценные Rules v3.

Целевая схема:

```text
UI
↓
ACTION
↓
HOST
↓
validation / rules
↓
REDUCER
↓
authoritative gameState
↓
broadcast
↓
all clients
```
